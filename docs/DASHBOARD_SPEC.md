# NOVA: Researcher Dashboard Specification

## 1. Dashboard Purpose & Target Audience

The **NOVA Researcher Dashboard** is a scientific research and data inspection tool built specifically for clinical researchers, psychology investigators, and affective computing engineers.

### Core Distinctions
- **NOT A PARTICIPANT UI**: The participant interacts exclusively with the Unity 3D embodied avatar via spoken dialogue and visual presence.
- **NOT A CLINICAL DIAGNOSTIC TOOL**: The dashboard never asserts clinical labels (e.g., "Participant has PTSD"). All displays report computational biomarkers, cross-modal attention weights, signal quality flags, and model prediction distributions calibrated with confidence bounds.
- **NO FAKE OR MOCKED SCORES**: Real measurements from processed signals are rendered. If an experiment or channel has not been evaluated, the interface displays **"Not evaluated"** or **"Unavailable"**.

## 2. Dashboard Layout & Functional Modules

The dashboard is structured into eight core scientific workspaces:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        NOVA RESEARCH CONSOLE                           │
├───────────────┬────────────────────────────────────────────────────────┤
│  NAVIGATION   │ WORKSPACE VIEW                                         │
│               │                                                        │
│  [1] Overview │ • Active Sessions • Health Status • Recent Cohorts    │
│  [2] Live     │ • Real-time Webcam/Audio Traces • Turn Processing     │
│  [3] Timeline │ • Synchronized Event Sequence & Modality Tracks        │
│  [4] Replay   │ • Chronological Playback with Step-through Inspection  │
│  [5] Cohort   │ • Pseudonymous Profiles • Longitudinal Trends          │
│  [6] Modality │ • Deep AU, Ocular, Acoustic, & Attention Inspection   │
│  [7] RL State │ • PPO Action Selection • Reward Terms • Topic Coverage │
│  [8] Models   │ • E0-E4 Ablations • Unimodal vs Fusion • Benchmarks   │
└───────────────┴────────────────────────────────────────────────────────┘
```

---

### Module A: Overview & Health Center
- **System Metrics**: Active sessions, completed interviews, registered pseudonymous participants, total dialogue turns logged.
- **Model Registry Health**: Real-time status cards for each registered pipeline module (`ASR / Whisper`, `Text / DistilRoBERTa`, `Voice / Acoustic DSP`, `Face / MediaPipe`, `Gaze / Iris`, `rPPG / Isolated`, `Fusion / Cross-Modal`, `RL / PPO Policy`).
- **Recent Sessions Table**: Pseudonymous ID, start time, duration, modality completion percentages, and session status (`active`, `completed`).

### Module B: Live Session Monitor
- **Active Participant Banner**: Pseudonymous participant ID, current session ID, elapsed time.
- **Current Turn Panel**: 
  - Last question presented by avatar.
  - Live transcript generated by Whisper ASR.
  - Modality extraction telemetry (signal quality scores, processing latency ms).
  - Cross-modal fusion output ($z_t$ projection, attention distribution).
  - PPO policy recommendation: selected question ID, question text, topic category, expected information gain.
- **WebSocket Streaming**: Live push updates from `/ws/dashboard/{session_id}` on every completed conversational turn.

### Module C: Synchronized Session Timeline
Implements the exact visualization documented in **Figure 7**:
1. **Dialogue Milestones**: Timestamped markers for each question asked ($Q_{01}$ Rapport, $Q_{02}$ Sleep, $Q_{03}$ Stressful event, $Q_{04}$ Avoidance, etc.).
2. **Continuous Biomarker Traces**:
   - **Gaze Aversion Index** ($[0.0, 1.0]$): Continuous curve with callout markers (`"elevated gaze aversion logged as evidence, not as a diagnosis"`).
   - **Vocal Instability** ($[0.0, 1.0]$): Cycle-to-cycle perturbation composite (jitter / shimmer / HNR inverse).
   - **Facial AU Activation** ($[0.0, 1.0]$): Composite of distress-related action units (AU04 Brow Lowerer, AU07 Lid Tightener).
3. **Modality Availability & Quality Track**:
   - Horizontal status bands for **Face**, **Gaze**, **Voice**, **Text**, and **rPPG**.
   - Distinct color-coded states:
     - 🟩 **Available** (Quality score $\ge 0.70$)
     - 🟨 **Degraded / Low Confidence** ($0.40 \le \text{Quality} < 0.70$)
     - ⬜ **Masked out of Fusion** (Quality $< 0.40$ or sensor unavailable)

### Module D: Chronological Session Replay
- Scrubbable time slider with Play / Pause / Step-Forward controls.
- Synchronized inspection of transcript, extracted features, modality masks, cross-attention weights, and PPO action distribution at that exact turn.

### Module E & F: Participant History & Longitudinal Analysis
- Participant profile strictly indexed by pseudonymous hash (e.g., `PARTICIPANT-74A8`).
- Historical sessions comparison table (dates, duration, turn count).
- Longitudinal trend graphs:
  - Acoustic stability trends over successive sessions.
  - Facial AU blunting / expressivity index over time.
  - Ocular fixation stability.
  - Topic coverage efficiency (turns to reach symptom coverage).

### Module G: Deep Multimodal Analysis
- **Action Unit Distribution**: Bar graphs for 13 action units (AU01, AU02, AU04, AU06, AU07, AU12, AU14, AU15, AU17, AU20, AU23, AU25, AU26).
- **Acoustic Profiling**: Fundamental frequency ($F_0$) distribution, jitter %, shimmer %, HNR (dB), and MFCC heatmap.
- **Ocular Dynamics**: 3D gaze angle polar plot, blink duration distribution, pupil diameter variance.
- **Cross-Modal Attention Heatmap**: $5 \times 5$ cross-attention matrix displaying how Face, Gaze, Voice, Text, and rPPG attend to one another during the current turn.

### Module H: Experiment & Benchmark Registry
- **Unimodal Baselines Table**: Performance of individual modalities (AUROC, F1, Precision, Recall, Accuracy).
- **Fusion Ablation Study (E0–E4)**:
  - $E_0$: Best single modality
  - $E_1$: Face + Voice
  - $E_2$: Face + Voice + Gaze
  - $E_3$: Face + Voice + Gaze + Text
  - $E_4$: Face + Voice + Gaze + Text + rPPG (active only if rPPG quality passed)
- **Architecture Comparison**: Early Fusion vs. Late Fusion vs. Cross-Modal Transformer.
- **RL Adaptive Policy vs. Fixed Script**:
  - Information gain per turn
  - Cumulative reward
  - Topic coverage rate
  - Turns to reach coverage threshold
  - Repetition rate
  - Safety violation count (must strictly be 0)
- Unrun experiments clearly labeled as **"Not evaluated"**.

## 3. Technology Stack & Implementation

- **Frontend Framework**: React 18 / TypeScript, Vite build tool.
- **Styling**: Tailwind CSS with clinical dark/light research aesthetic.
- **Visualization**: Recharts & Lucide icons for high-performance canvas/SVG time series rendering.
- **Live Communication**: Native HTML5 WebSockets connected to FastAPI backend.
- **Static Assets & Build**: Production build bundled into `dashboard/dist` and directly servable via FastAPI static files mounting or standalone Vite dev server.
